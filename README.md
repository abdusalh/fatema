# Shabiyat Fatima — Restaurant Website

A premium Arabic RTL landing page for **شعبيات فاطمة**.

## Run locally

No build step is required.

1. Open the project folder in VS Code.
2. Open `index.html` with Live Server, or double-click the file.
3. Replace placeholder contact information and food prices before publishing.

## Project structure

- `index.html` — main page
- `css/style.css` — responsive visual system
- `js/script.js` — navigation, menu filters, scroll reveal, back-to-top
- `images/` — reserved folders for official restaurant assets

## Important

The current food/heritage imagery uses remote image URLs as visual placeholders. Replace these with approved restaurant photography before production launch.

Do not publish placeholder phone numbers, addresses, prices, or social links.
